# EduCheck

Student-led school oversight web app (HTML prototype), inspired by CERC's Integrity Clubs in schools.

Features: issue reporting with photo and location, status tracking (reported, acknowledged, fixed, verified), school directory with list and map, analytics dashboard with CSV export, role switching, FR/EN/Lingala/Kikongo labels, offline queue, relevance feedback.

All data is demo data. Lingala and Kikongo labels are drafts and need native-speaker review.

## Run
Open `index.html` in a browser. No build step.

## Deploy on GitHub Pages
Settings, Pages, Deploy from branch, `main` / root.
